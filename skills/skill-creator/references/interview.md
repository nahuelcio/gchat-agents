# Interview checklist

Ask at most 1–2 focused questions per turn. Prefer extracting answers from the conversation first.

1. **Job** — What should an agent *do* after this skill is attached?
2. **Trigger** — What user phrases / situations should light it up?
3. **Output** — Link, table, short reply, file, ticket…?
4. **Tools** — Drive? Code? Switchboard? A custom script?
5. **Never-dos** — Invent numbers? Edit disk? Call other agents?
6. **References** — Long policy / SLA / format docs → `references/`.
7. **Scripts** — Repeatable transforms (PDF, CSV) → `scripts/` stub + body says when to run it.

If the user already pasted a workflow, draft first, then ask only for gaps.
