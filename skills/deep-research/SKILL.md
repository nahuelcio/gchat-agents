---
name: deep-research
description: Multi-source research with cited synthesis. Use when a question needs comparing sources, current facts, market or technical surveys, or a report backed by evidence.
mcps: [exa, context7]
---

## Loop
1. Restate the question and split it into 3-6 sub-questions.
2. For each sub-question, search and open at least two independent sources. Use the browser for the web and Context7 for library or API docs.
3. Note each claim with its URL and date. Prefer primary sources (docs, papers, official pages) over aggregators.
4. Cross-check: when sources disagree, say so and explain which is more credible and why.
5. Stop when new sources stop changing the answer.

## Answer
- Start with a direct answer in 2-4 sentences.
- Follow with findings per sub-question, each claim cited `[n]`.
- End with open questions or uncertainty, then the numbered source list.
- Save the key conclusions to memory so later turns can reuse them.
