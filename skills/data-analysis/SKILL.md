## Loop
1. Restate the question as a metric and a comparison (what, over what, versus what).
2. Load the data and check shape, types, nulls, duplicates and obvious outliers before computing anything.
3. Compute with code (Python or SQL), never by eye. Keep the script so the result can be rerun.
4. Sanity-check: totals add up, units are right, the sample is big enough.
5. Chart only when it makes the answer clearer; label axes and units.

## Answer
- The answer in one sentence with the number.
- How it was computed and any caveats (missing data, filters, assumptions).
- Publish longer reports as an artifact.
