# Formato de planillas

## Celdas numéricas

- Montos y cantidades: número puro (`1234.56`), nunca `"$1.234,56"` ni texto.
- Fechas: ISO `YYYY-MM-DD` cuando el usuario no pide otro formato.
- Porcentajes: decimal (`0.15` = 15%) salvo que pidan mostrar `%` en otra columna de texto.

## Hojas

- Una hoja = una tabla.
- Fila 1 = encabezados cortos en español (sin espacios raros al final).
- No mezclar totales con el detalle en la misma columna sin avisar.

## Nombre de archivo

- Preferí `cierre-YYYY-MM.xlsx` o el nombre que dé el usuario.
- Si no hay mes claro, preguntá una sola vez.
